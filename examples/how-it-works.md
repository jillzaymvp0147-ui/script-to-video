## hook
> code: python make.py how-it-works.md | ✓ voice | ✓ captions | ✓ render
This whole video started as a text file. One command turned it into what you're watching.

## scenes
> list: ## hook | ## scenes | ## voice | ## timing
> headline: Every heading is a scene
Every heading in the file is a scene. Every line under it is what the voice says.

## voice
> number: $0 | API cost per video
A free voice model reads it out, right on your computer. No account, no API key, no bill.

## timing
> headline: Every *word* on time
Then Whisper listens back and marks the moment each word is spoken. That's how these captions keep up.

## visuals
> list: Headline | Counter | Checklist | Terminal | Your image or clip
One line picks the picture for each scene: a headline, a counter, a checklist, a terminal, or your own image or clip.

## formats
> headline: 9:16 *and* 16:9
The same script renders as a vertical Short and a wide video, with the loudness set for YouTube.
